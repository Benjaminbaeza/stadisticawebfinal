Objetivo del ejercicio

El ACP (o PCA por sus siglas en ingles) es una técnica estadistica que permite reducir el número de variables de un conjunto de datos, conservado la mayor cantidad posible de información.

En el presente practico, se tiene como objetivo que los y las estudiantes realicen un Análisis de Componentes Principales con el fin de que comprendan o se familiaricen no solo con su realización, sino que a su vez con su comprensión a partir de sus datos y por ende con su interpretación, para aquello se les enseñara a realizar el ACP de dos formas distintas por medio de las posibilidades que permite el software de Rstudio. Tambien se introduciran las nociones basicas de como elaborar un indice, en Rstudio, en su forma basica (sin indicadores o escala).

Ejercicio a desarrollar

Siguiendo los siguientes pasos en la base de datos del ELSOC, se realizara un Analisis de Componentes Principales; a partir de las variables correspondientes al módulo de Cohesión Barrial y Sociabilidad Barrial siendo 8 variables en total, se realizara el ACP, con el fin de reducir el conjunto de datos, manteniendo la mayor cantidad de información posible. a Su vez de forma posterior, se espera que se elabore un indice de Cohesión Barrial.

3.1 Transformación de valores perdidos a NA

proc_data <- proc_data %>%
  sjlabelled::set_na(.,na = c(-999, -888, -777, -666))

# Esto se realiza en este caso porque el ACP, trabaja con variables de tipo
# Cuantitativas o numericas

proc_data <- proc_data %>%
  mutate(across(everything(),
      ~ as.numeric(as.character(.))))

Paso 4: Matriz de correlaciones

4.1 Elaboración y visualización de la matriz de correlaciones

matriz_cor <- cor(proc_data_pca) # cor, es el apócope/acortamiento/abreviación
                                 # de la palabra correlation; correlación en
                                 # ingles

matriz_cor # Se le indicamos R que corra el objeto creado, nos permitira
           # observar en la consola, la correlación entre las variables

# Podemos visualizar la matriz de correlaciones de una forma grafica
corrplot(matriz_cor, method = "number")

Las correlaciones oscilan entre valores correspondientes al 1 y -1; donde 1 es correlación positiva (Ambas variables suben si sube el valor de una) y -1 es correlación negativa (Mientras una variable sube, la otra baja). Dependiendo de manual de referencia o los critetirios metodologicos que se ocupen; la correlaciones se conciben de la siguiente forma: (1) 0.3 a 0.5 correlación leve (2) 0.6 a 0.7 correlación media o moderada (3) 0.8 o más correlación alta

Medimos el grado de correlación entre las variables para determinar si es que estan relacionadas entre si; y si se estima razonable continuar con el uso de las mismas o se debiarian excluir. Por ejemplo para elaborar un indice como haremos ya hacia el final del practico, requerimos que todas las variables tengan algun grado de correlación para la elaboración del mismo.
