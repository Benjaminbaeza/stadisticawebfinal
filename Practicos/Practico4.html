🎯 Objetivo del Ejercicio

El siguiente practico tiene como objetivo aplicar técnicas de clustering jerárquico utilizando el método del centroide para identificar grupos (conglomerados) en una base de datos con los datos base y posteriormente estandarizados. El análisis se basa en la distancia euclidiana al cuadrado como medida de disimilitud. Se menciona y presenta el método de Ward en su elaboración como metodo alterno.

0,2 decimas para el Control 1 (0,1 decima por script y 0,1 por interpretación)

Interpretación al final del script

2.2. Selección de variables del ELSOC para el Analisis de Conglomerados.

# Filtrar ola 4 y seleccionar variables numéricas

datos_cluster <- elsoc_long_2016_2022.2 %>%
  filter(ola == "4") %>%
  select(m0_edad,    # Edad
         m13,        # Ingreso mensual entrevistado
         m01         # Nivel educacional)

# Creamos asi nuestra sub-base de datos_cluster que solo tiene las variables con las
# que trabajaremos, ademas a esta se les eliminaran los NA.
# Con esta sub-base trabajaremos durante el resto del practico

# ******NOTA******

# La variable m13 de ingresos es un indicador directo
# por lo que el monto indicado de esta, es el monto total de ingresos mensuales
# del entrevistado; ELSOC tambien tiene otras variables que miden el ingreso
# mensual por tramos m14 (16 tramos) y m14b (5 tramos).
# para quienes tengan la duda, de porque trabajamos con la variable m13 por sobre
# m14 o m14b, es porque estas dos variables, no se encuentran disponibles en la
# Ola 4 (2019), no fueron preguntadas o en su momento no eran contempladas
Note

El Analisis de Conglomerados permite el uso de variables cualitativas y cuantitativas; de ahi que usemos la edad y el ingreso que son numericas y la educación como variable ordinal.

2.2.1. Limpieza de Variables

#  Transformamos los valores perdidos a NA

datos_cluster <- datos_cluster %>%
  sjlabelled::set_na(
    na = c(-999, -888, -777, -666, 999999999))

# Los eleminamos de la base

datos_cluster <- na.omit(datos_cluster)

# Vemos la estructura de los datos resultantes

summary(datos_cluster) # Podemos observar la medidas de tendencia central

dim(datos_cluster) # Vemos las dimensiones; siendo el numero de observaciones
                   # y variables
Note

Los más observadores veran que indique el valor 999999999, como valor perdido y por ende NA. Esta observación corresponde a un dato de la variable m13, ingreso mensual, elimine dicha observación, por que en caso de mantenerse figuraria como un valor extremos, sesgando resultados, ademas el encuestado con el segundo mayor monto de ingresos era radicalmente inferior a dicho valor; ante la duda de ser un error de registro o una observación valida, opte por elimanrlo, decisión metodologíca.

⚖️ Paso 3: Estandarización de Variables

Es fundamental estandarizar las variables para que todas tengan la misma escala (media = 0, desviación estándar = 1).

# Estandarizar (normalizar) las variables

Z <- scale(datos_cluster) # Z, corresponde al Puntaje Z, de estandarización
                          # de variables; lo llamamos asi, porque ocuparemos
                          # en diversas ocasiones a lo largo del practico
                          # y asi, seria más facil de identificar

# Verificamos el puntaje Z, para ver si resulto

head(Z) # Con este podemos observar los primeros casos 

summary(Z)  # # Podemos observar la medidas de tendencia central del mismo

📐 Paso 4: Calcular la Distancia Euclidiana

Calculamos la matriz de distancias euclideanas entre todos los casos.

# Calcular distancia euclidiana

d <- dist(Z, method = "euclidean")

# Ver dimensión de la matriz de distancias

print(d)

🔲 Paso 5: Elevar al Cuadrado las Distancias

# Para elevarla al cuadrado, debemos usar el objeto d, anteriormente creado
# que es nuestra distancia euclidiana y la elevamos al cuadrado (^2)

d2 <- d^2 # creamos un nuevo objeto que seria la distancia euclidiana al cuadrado
          # esta seria d2, la guardamos como un objeto porque tambien haremos uso
          # de esta durante el practico

🌲 Paso 6: Ejecutar el Análisis de Conglomerados (Método Centroide)

# Aplicamos el clustering jerárquico mediante el método centroide

hc <- hclust(d2, method = "centroid") # ocupamos la distancia euclidiana al cuadrado 

# Revisar información del objeto

names(hc)

# Comprobar método utilizado

hc$method # deberia decir "centroid"

# Número de observaciones

length(hc$order) # deberia de ser 2021 que es el numero de observaciones
                 # de la base con la que trabajamos

plot(hc, hang = -1, main = "Clustering jerárquico - Método Centroide")

✂️ Paso 9: Asignar los casos a los Conglomerados

Una vez decidido el número de grupos (k), asignamos cada caso a su conglomerado.

# Definir número de grupos

k <- 4 # En este caso 4

# Cortar el árbol en 4 grupos

grupos <- cutree(hc, k = k) # creamos el objeto que contenga el numero de
                            # Clusters por el que fue cortado el Analisis
                            # de Conglomerados por el metodo de centroide

datos_cluster$grupo <- grupos # Asiganos este objeto creado a la sub-base de datos
                              # como una variable; si salio bien, debera de ver
                              # que la sub-base paso de tener 3 variables a 4
                              # y si la abren veran que la variable grupo tendra
                              # valores de 1 a 4 en cada observación; el numero
                              # indicara, a cual cluster pertenece cada caso

Paso 10: cantidad de casos por conglomerados

table(datos_cluster$grupo) # Podemos crear una tabla que nos indica la cantidad de 
                           # casos que conforma cada cluster

prop.table(table(datos_cluster$grupo)) # Tambien podemos saber lo mismo, pero
                                       # indicado en proporción

Paso 11: caracterización de conglomerados

datos_cluster %>%
  group_by(grupo) %>%
  summarise(across(where(is.numeric),
      ~ mean(.x, na.rm = TRUE))

# Obtenemos las medias de cada variable agrupadas en función del conglomerado
# al que pertenezcan.

Paso 12: caracterización con datos estandarizados

# Tambien podemos obtener los valores de cada variable en relación
# al coglomerado; con un valor estadarizado para todas, el puntaje Z
# de esta forma la unidad de medida de las variables corresponderia
# al mismo

datos_z <- as.data.frame(Z) # Creamos una nueva sub-base de datos a
                            # partir del puntaje Z

datos_z$grupo <- grupos # A dicha sub-base le agregamos los grupos de
                        # Conglomerados que realizamos con anterioridad

datos_z %>%
  group_by(grupo) %>%
  summarise(across(where(is.numeric),
      ~ mean(.x, na.rm = TRUE)))

# Obtenemos las medias de cada variable agrupadas en función del conglomerado
# al que pertenezcan; pero esta vez con un puntaje estandarizado.
