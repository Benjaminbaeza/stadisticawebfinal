🎯 Sobre este ejercicio

Este ejercicio corresponde al Control 2 y tiene un valor de 0,2 puntos. Consiste en diseñar una propuesta de investigación sociológica que pueda ser respondida utilizando al menos uno de los siguientes métodos multivariantes:

  • Análisis de Correspondencias (Simple o Múltiple)

  • Análisis de Componentes Principales (PCA)

  • Análisis Factorial Exploratorio (AFE)

La propuesta debe incluir cuatro elementos fundamentales:

  • Pregunta de investigación (clara, precisa y abordable con los datos)

  • Dimensiones del análisis y posibles variables (qué conceptos medir y con qué ítems)

  • Base de datos y módulos (dónde obtener los datos)

  • Propuesta de modelo justificada (qué método usar y por qué)

A continuación, se presenta una propuesta desarrollada a partir de los análisis realizados en prácticos anteriores, utilizando datos del Estudio Longitudinal Social de Chile (ELSOC).

🔍 Pregunta de investigación

¿Existen dimensiones subyacentes en las actitudes hacia la inmigración en Chile, y cómo se relacionan estas dimensiones con características sociodemográficas como nivel educacional, posición política y sexo?

Elaboración propia basada en datos del Estudio Longitudinal Social de Chile (ELSOC) - COES

Base de datos y módulos:

  • Base de datos: Estudio Longitudinal Social de Chile (ELSOC) - Ola 4 (2019)

  • Institución: Centro de Estudios de Conflicto y Cohesión Social (COES)

Módulos utilizados:

  • Inmigración: Variables: r09, r12_01, r12_02, r12_03, r12_04, r16

  • Sociodemográfico: Variables: m01, m01_sexo, eje_politico

Propuesta de Modelo Justificado

Para responder a la pregunta de investigación, se propone el siguiente esquema analítico:

  • Paso 1: Identificar dimensiones subyacentes en las actitudes hacia inmigrantes.
  • Paso 2: Asociar esas dimensiones con variables sociodemográficas.

Dependiendo del enfoque, se puede elegir entre tres métodos multivariantes:

  • Comparación de Métodos: ¿Cuándo usar cada uno?

1. Análisis de Componentes Principales (PCA)

¿Qué hace? - Reduce un conjunto de variables correlacionadas a un número menor de componentes (combinaciones lineales) que retienen la máxima varianza posible.

¿Cuándo usarlo?

  • Cuando las variables son numéricas continuas (o escalas Likert tratadas como continuas)

  • Cuando el objetivo es reducir dimensionalidad para construir un índice

  • Cuando no interesa identificar “factores latentes” sino resumir información

Ejemplo en esta investigación:

Podría usarse para crear un índice de actitud hacia inmigrantes combinando r09, r12_01, r12_02, r16 en una sola variable que resuma la “apertura”.

  • Ventajas: Simple, no asume estructura latente, útil para predicción.
  • Limitación: No identifica factores no observados (solo combina los observados).

2. Análisis Factorial Exploratorio (AFE)

¿Qué hace? - Identifica factores latentes (no observados) que explican las correlaciones entre las variables. Asume que las variables observadas son manifestaciones de constructos subyacentes.

¿Cuándo usarlo?

  • Cuando se busca entender la estructura subyacente de los datos

  • Cuando hay teoría previa sobre dimensiones que podrían existir (ej. “apertura” y “amenaza”)

  • Cuando se espera que las variables midan constructos no directamente observables

Ejemplo en esta investigación:

Ideal para confirmar si las actitudes hacia inmigrantes se organizan en dos dimensiones: una de apertura positiva (r09, r12_01, r12_02, r16) y otra de amenaza (r12_03, r12_04).

  • Ventajas: Identifica estructura latente, permite rotación para mejor interpretación.
  • Limitación: Requiere decisiones subjetivas (número de factores, tipo de rotación).

3. Análisis de Correspondencias (ACS / ACM)

¿Qué hace? - Analiza la asociación entre variables categóricas. ACS para dos variables, ACM para tres o más. Representa las categorías en un mapa perceptual donde la proximidad indica asociación.

¿Cuándo usarlo?

  • Cuando las variables son categóricas (nominales u ordinales)

  • Cuando se quiere visualizar asociaciones entre categorías

  • Cuando se busca identificar perfiles (combinaciones de categorías)

Ejemplo en esta investigación:

Se podría usar ACM para explorar la asociación entre:

-Actitud hacia inmigrantes (recodificada en: Baja / Media / Alta)

  • Nivel educacional (Básica / Media / Superior)

  • Posición política (Izquierda / Centro / Derecha)

  • Sexo (Hombre / Mujer)

  • Ventajas: No asume linealidad, visualización intuitiva, maneja variables categóricas.
  • Limitación: No identifica dimensiones latentes como el AFE, solo asociaciones entre categorías.
📊 Propuesta metodológica para la investigación
Objetivo Método Recomendado Justificación
Identificar dimensiones subyacentes en actitudes hacia inmigrantes AFE Permite confirmar si existe estructura bifactorial (apertura vs. amenaza)
Relacionar esas dimensiones con variables sociodemográficas ACM Las variables sociodemográficas son categóricas; ACM visualiza perfiles
Nota: AFE = Análisis Factorial Exploratorio; ACM = Análisis de Correspondencias Múltiple. Ambos métodos se complementan para abordar los dos objetivos planteados.

Elaboración propia en base a los análisis realizados en prácticos anteriores

Estrategia alternativa:

Si se prefiere un enfoque más simple, se puede usar PCA para construir un índice de actitud y luego correlacionarlo con las variables sociodemográficas.

Conclusión

La elección del método depende del objetivo específico:

  • PCA: Resumir información en un índice

  • AFE: Descubrir estructura latente subyacente

  • ACS/ACM: Explorar asociaciones entre variables categóricas

Para esta investigación, se recomienda AFE para identificar dimensiones de actitud hacia inmigrantes, seguido de ACM para relacionar esas dimensiones con características sociodemográficas.
