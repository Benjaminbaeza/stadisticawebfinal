Objetivo del Análisis

El Analisis Factoria o (AF) por sus siglas es una técnica estadística que permite identificar en un conjunto reducido de factores su comportamiento latentes con el cual se explica las relaciones entre varias variables observadas. Como bien se planteo en el practico anterior (practico 8) este tipo de analisis nos permite principalmente medir fenomenos sociales o estadisticos los cuales son indirectos y no empirica o directamente observables; en este practico ocuparemos dicha capacidad o posibilidad para elaborar un indice propio.

Por lo que el objetivo de este analisis, consisten en realizar un análisis factorial exploratorio en el cual a partir de sus resultados (los factores compuestos a partir de las variables seleccionadas) podemos elaborar un indice propia; en este caso correspondiente al concepto de “Satisfacción Residencial”.

Ejercicio a desarrollar

Siguiendo los siguientes pasos en la base de datos del ELSOC, el ejercico a desarrollar consiste en elaborar un Analisis Factorial Exploratorio (AFE) con el fin de reducir la dimensionalidad de una batería de variables para en este caso medir el concepto en particular de “Satisfacción Residencial”. A partir de los factores obtenidos (y la distribución de las variables en estos), se esperan obtener una aproximación de las dimensiones que compondria dicho fenomeno que buscamos medir; posteriormente procederiamos a realizar un “Indice de Satistafacción Residencial” a partir de dichas dimensiones.

Paso 7: Elaboración del indice

7.1 Creación de las dimensiones del indice

# Sabiendo que el numero de factores son 4; y a su vez sabiendo
# cuales serian las variables que los compondrian.

# Determinamos que la "Satisfacción Residencial" se haya
# compuesta de 4 dimensiones cada una representada por
# cada uno de los factores.

# Dichas dimensiones serian: la Identitaria; la Material;
# la Ambiental y por ultimo la Ocupacional

# Ocupamos la funcuón "rowwise()" de el paquete dplyr para
# agrupar los datos fila por fila.
# con mutate creamos nuevas columnas de variables o modificamos 
# columnas existentes en un conjunto de datos.

# En este caso las nueva columnas de variables corresponderian
# a cada uno de las dimensiones de la satisfacción residencial;
# dimensiones concebidas a partir de los factores los cuales
# estarian compuestos de las variables asociadas a cada factor. 
# cada veriables estarian concatenada (c) t consideraria las 
# medias (mean) de las variables que la componen.

# ungroup() se utiliza para deshacer la estructura de agrupación 
# creada previamente por la función que hemos realizado o
# utilizado

# Cada una de estas acciones corresponden al paquete dplyr

proc_data_2022 = proc_data_2022 %>% 
  rowwise() %>% 
  mutate(Identitaria = mean(c(Barrio_ideal, Integra_barrio, Identi_gente, Parte_barrio)),
         Material = mean(c(Satis_tamano_viv, Satis_calidad_viv)),
         Ambiental = mean(c(Satis_seguridad, Satis_conectividad, Satis_cerca_comerc, Satis_barrio_limp)),
         Ocupacional = mean(c(Satis_cerca_amig_fami, Satis_cerca_trab, Satis_cerca_coleg, Satis_area_ocio))) %>% 
  ungroup()

7.2 Creación del indice y peso de las dimensiones del indice

# Con las dimensiones creadas confeccionamos el indice a 
# partir de estas.

# La estructura es similar al paso anterior ya que seguimos ocupando
# funciones de dplyr como "rowwise"; "mutate" y ungroup.

# La variable correspondiente al indice en su totalidad,
# esta compuesta a partir de la suma los valores de las dimensiones; 
# el cual recordemos que son variables construidas a partir de las 
# medias de las variables que componen cada factor.

# A la suma de estas variables para componer la variable 
# correspondiente al indice general; se debe mencionar que cada una 
# de estas fue multiplicada por (*0.25); aquello se interpreta
# como la asignación del peso de cada una de las variables.
# Nos aseguramos que cada una pesase lo mismo para evitar la
# sobre representación de una dimensión por sobre la otra y
# aquella es la razón de que la variable lleve el sufijo
# ponderada.

proc_data_2022 = proc_data_2022 %>% 
  rowwise() %>% 
  mutate(Satisfación_residen_pond = (Identitaria*0.25) + (Material*0.25) + (Ambiental*0.25) + (Ocupacional*0.25)) %>% 
  ungroup()
