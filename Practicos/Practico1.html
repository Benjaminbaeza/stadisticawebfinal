🎯 Objetivos del Práctico

Propósito General

Este práctico introductorio tiene como objetivo desarrollar competencias fundamentales para el manejo y exploración inicial de bases de datos, sentando las bases para análisis estadísticos posteriores.

Mediante el trabajo en grupo, los estudiantes aprenderán a:

  1. Seleccionar y explorar una base de datos, comprendiendo su estructura y contenido.

  2. Identificar y tratar problemas comunes como valores perdidos y casos atípicos (outliers).

  3. Clasificar variables según su escala de medición (nominal, ordinal, continua, de razón).

  4. Recodificar variables para facilitar su análisis posterior.

  5. Formular preguntas de investigación relevantes a partir de los datos disponibles.

  6. Realizar un análisis descriptivo inicial mediante tablas de frecuencia y tablas de contingencia.

Paso 1: Selección de la base a utilizar.

Elijan una base de datos que sea de su interés. Puede ser:

  1. Una base de datos propia (de su disciplina o investigación).

  2. Datos públicos de repositorios como Harvard Dataverse, Kaggle, INE (institutos nacionales de estadística), etc.

En este caso para este practico trabajaremos como la base de datos del ENUSC (Encuesta Nacional Urbana de Seguridad Ciudadana) del año 2024 en su formato .sav

Paso 3: Imaginación de una pregunta de investigación

Antes de limpiar que es el paso que vamos a ver a continuación, piensen: ¿qué les gustaría investigar con estos datos? No necesita ser definitiva, pero les ayudará a enfocar el trabajo. Por ejemplo:

  • “Queremos saber si existe relación entre el nivel educativo y la confianza en instituciones.”

  • “Nos interesa explorar cómo varía el ingreso según la región.”

Aqui el unico limite es la imaginación y la propia base de datos con la que estemos trabajando, lo ideal es que la pregunta sea pertinente, interesante y abordable sociologicamente, y obvio, que tenga relación directa con los datos que vas a utilizar.

Paso 5: Tablas cruzadas para explorar posibles relaciones.

cat("\n=== TABLAS CRUZADAS ===\n")

# RPS por Sexo (ser víctima de robo en la calle seún sexo)
cat("\nRPS por Sexo:\n")
datos %>%
  filter(!is.na(rps) & !is.na(sexo)) %>%
  group_by(sexo) %>%
  summarise(
    media_rps = mean(rps, na.rm = TRUE),
    n = n(),
    .groups = 'drop'
  ) %>%
  print()
