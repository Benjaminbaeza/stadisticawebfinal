1. 🎯 Objetivos del Práctico

Propósito General

Este práctico tiene como objetivo desarrollar competencias en el Análisis de Correspondencia Múltiple (ACM) mediante:

  1. Aplicación del Análisis de Correspondencia Simple (ACS) para explorar la relación entre lsa diversas variables categóricas.

  2. Aplicar Análisis de Correspondencia Múltiple (ACM) para explorar relaciones entre tres o más variables categóricas.

  3. Interpretar los resultados fundamentales: masa, inercia, contribuciones y mapa perceptual.

  4. Visualizar y comunicar las asociaciones entre categorías de manera efectiva.

2. Contexto del Practico

La Base de Datos con la que nos dispondremos a trabajar, corresponde a la del Estudio Longitudinal Social de Chile (ELSOC), más especificamete con su cuarta ola correspondiente a las observaciones realizadas en el año (2019); ELSOC es una encuesta panel representativa a nivel nacional.

Por lo que en este practico, se les dispondran una serie de cinco variables del ELSOC; a partir de estas se espera que Analisis de Correspondecia Múltiple (ACS) para la realización de un analisis de este tipo con dichas variables y realizar una interpretación del mismo a partir de todos los resultados en su conjunto.

datos_acs <- elsoc_long_2016_2022.2 %>%

# Lo interesante de este punto es que sin nos fijamos, R nos indica

4.2. Recodificación de variables

# Con recode, podemos recodificar las variables que estamos trabajando, para
# agrupar categorias de respuestas
# En el caso de la variable m01 agrupamos sus 10 categorias de respuestas
# en 3.

# la misma logica se realizarian con el resto de variables

datos_acs$educacion <- car::recode(
  datos_acs$m01,
  "c(1,2,3)=1; c(4,5)=2; c(6,7,8,9,10)=3")

# Con factor hacemos que la variable pase de numeric a factor
# factor es la forma en que se leen variables ordinales

datos_acs$educacion <- factor(
  datos_acs$educacion,
  levels = c(1, 2, 3),
  labels = c("Educación básica", "Educación media", "Educación superior"))

# Algo importante y para saber que el comando se ejecuto correctamente
# más alla de que nos indique ERROR, es que por cada variable recodificada
# se creara una nueva a en la base de datos
# por lo que realizado este paso deberiamos de tener 10 variables
# 1 extra por cada variable recodificada


datos_acs$confianza_gob <- car::recode(
  datos_acs$c05_01,
  "c(1,2)=1; c(3)=2; c(4,5)=3")

datos_acs$confianza_gob <- factor(
  datos_acs$confianza_gob,
  levels = c(1, 2, 3),
  labels = c("Desconfianza en el gobierno", "Indiferente con el gobierno",
             "Confianza en el gobierno"))

datos_acs$confianza_presi <- car::recode(
  datos_acs$c05_08,
  "c(1,2)=1; c(3)=2; c(4,5)=3")

datos_acs$confianza_presi <- factor(
  datos_acs$confianza_presi,
  levels = c(1, 2, 3),
  labels = c("Desconfianza en el presidente", "Indiferencia con el presidente",
             "Confianza en el presidente"))

datos_acs$auto_pospol <- car::recode(
  datos_acs$c15,
  "c(0,1,2)=1; c(3,4)=2; c(5)=3; c(6,7)=4;
   c(8,9,10)=5; c(11)=6; c(12)=7")

datos_acs$auto_pospol <- factor(
  datos_acs$auto_pospol,
  levels = c(1, 2, 3, 4, 5, 6, 7),
  labels = c("Izquierda", "Centro izquierda", "Centro", "Centro derecha",
    "Derecha", "Independiente", "Apolitico"))

datos_acs$Cambio_const <- car::recode(
  datos_acs$c28,
  "c(1,2)=1; c(3)=2; c(4,5)=3")

datos_acs$Cambio_const <- factor(
  datos_acs$Cambio_const,
  levels = c(1, 2, 3),
  labels = c("En desacuerdo con cambiar la constitución",
    "Ni de acuerdo ni en desacuerdo con cambiar la constitución",
    "De acuerdo con cambiar la constitución"))
