Objetivo del Análisis

El Analisis Factoria o (AF) por sus siglas es una técnica estadística que permite identificar en un conjunto reducido de factores su comportamiento latentes con el cual se explica las relaciones entre varias variables observadas. Este tipo de analisis se realiza principalmente para medir fenomenos sociales o estadisticos los cuales son indirectos o no empirica o directamente observables, los cuales en los cursos metodologícos podiamos entender como aquellos fenomenos los cuales no pueden ser capactados por indicadores directos, sino que compuestos.

El objetivo de este analisis, consisten en comprender y estimar un análisis factorial exploratorio en el cual se espera que por medio de su desarrollo, los estudiantes entiendan la logica tras este tipo de analisis, familiarizandose con su realización y su interpretación.

Ejercicio a desarrollar

Siguiendo los siguientes pasos en la base de datos del ELSOC, el ejercico a desarrollar consiste en elaborar un Analisis Factoria (AF) exploratorio con el fin de reducir la dimensionalidad de una batería de variables para en este caso medir el concepto en particular de la “Confianza en instituciones”.

Por lo que durante el transducros del parctico se les enseñara a obtener de una forma alterna los descritivos de las variables empleadas y la viasualización de correlaciones en formato tabla. Se realizaran analisis paralelos para familiarizarse con la determinación del numero de factores que se obtendria con este tipo de analisis elemento difiderenciador de los otros metodos de analisis estastidisticos vistos en el curso -Analisis de Conglomerados y ACP-. Ademas de los distintos metodos o enfoques existentes al momento de realizar el (AF) que se pueden aplicar para la obtención de sus resultados y la obtención de sus cargas factoriales. Por ultimo, con los resultados obtenidos, se enseñara como se puede compaginar el Analisis Factorial Exploratorio, con otro tipo de analisis estadistico, el cual corresponderia a las regresiones lineales (en su forma simple y multiple).

Paso 5: Análisis factorial exploratorio

Pero ¿Qué podemos deducir de la matriz de correlaciones en relación a la estructura subyacente en términos de variables latentes? Sabemos que las variables tienen una consistencia interna alta y estan correlacionadas en algun punto. Más debemos determinar la claridad de grupos de indicadores asociados entre sí.

5.1 Test de adecuación de matriz para AFE

KMO (Kaiser, Meyer, Olkin Measure of Sampling Adequacy):

  • Varía entre 0 y 1. Contrasta si las correlaciones parciales entre las variables son pequeñas

  • Valores pequeños (menores a 0.5) indican que los datos no serían adecuados para AFE, ya que las correlaciones entre pares de variables no pueden ser explicadas por otras variables.

corMat  <- data %>% select(conf_gob:conf_pres) %>%
  cor(use = "complete.obs")  # estimar matriz pearson

KMO(corMat)

5.2 Nivel de correlaciones de la matriz: test de esfericidad de Barlett

Se utiliza para evluar la hipótesis que la matriz de correlaciones es una matriz identidad (diagonal=1 y bajo la diagonal=0)

  • Se busca significación (p < 0.05) ya que se espera que las variables estén correlacionadas
cortest.bartlett(corMat, n = 3417)

# Recordemos que cuando hacemos estos test que consideran valor p

5.4 Extración de valores de los factores

Los métodos de extracción son los procedimientos estadísticos que se utilizan para identificar y estimar los factores latentes que podrían explicar las correlaciones entre las variables observadas. O sea que apartir de estos determinamos como se estiman los factores.

En este caso veremos 2 distintos y cada uno tienen sus determinadas caracteristica.

5.4.1 Ejes principales (Principal Axis Factoring)

Este estima qué parte de la variabilidad de cada variable comparte con las demás y utiliza esa información para extraer factores. Podemos utilizarlo cuando queremos identificar dimensiones latentes y no necesitamos asumir que los datos siguen una distribución normal o multivariante.

Su principal ventaja es que: es un método clásico y útil para el análisis exploratorio.

Su principal limitación es que: puede requerir iteraciones y no siempre produce una solución adecuada.

5.5 Rotaciones

Cuando extraemos dos o más factores, las cargas factoriales iniciales pueden quedar distribuidas de una manera difícil de interpretar. La rotación que veremos en estos casos reorganizan matemáticamente los ejes factoriales para intentar conseguir una estructura más clara. Existen principalmente 2 tipos de rotaciones con sus determinados tipos, para este caso veremos una de cada 1.

5.5.1 Rotación Ortogonal - Tipo Varimax

Es una de las rotaciones más conocidas. Busca simplificar las cargas factoriales haciendo que, dentro de cada factor, algunas cargas sean relativamente altas y otras bajas.

Su principal ventaja es que: facilita la interpretación de los factores.

** Su principal limitación** es que: supone que los factores no están correlacionados.

# Analisis Factoria Exploratorio 
# Extracción: Método de Máxima Verosimilitud
# Rotación: Varimax

fac_ml_var <- data %>% select(conf_gob:conf_pres) %>% fa(nfactors = 3, fm= "ml", rotate="varimax") # ortogonal

# nfactors = 3; al igual que en en los codigo anteriores; 
# corresponde al numero de factores que queremos estimar
# fm= "ml"; corresponde al metodo de extracción; Maxima verosimilitud
# rotate= es donde indicamos el tipo de rotación; en este caso "varimax"

fac_ml_var # Corriendo este codigo podemos observar sus datos

5.5.2 Rotación Oblicua - Tipo Promax

Promax es una rotación oblicua la cual parte de una solución ortogonal y la transforma para permitir que los factores estén correlacionados. Nos puede resultar útil cuando quieremos una estructura sencilla y permite correlaciones entre factores.

Su principal ventaja es que: suele ser computacionalmente eficiente.

# Analisis Factoria Exploratorio 
# Extracción: Método de Máxima Verosimilitud
# Rotación: Promax

fac_ml_pro <- data %>% select(conf_gob:conf_pres) %>% fa(nfactors = 3, fm= "ml", rotate="promax")

# rotate= es donde indicamos el tipo de rotación; en este caso "promax"

Paso 6: Puntajes factoriales

Luego de realizar el Análisis factorial exploratorio existen varias alternativas sobre los pasos a seguir. Por ejemplo, es posible estimar un promedio simple entre cada una de las variables de los factores. Otra opción es estimar puntajes factoriales que es lo que en este paso se procedera a realizar.

Pero ¿que son los puntajes factoriales? Los puntajes factoriales (factor scores) son valores numéricos que representan la posición de cada individuo en los factores identificados mediante un análisis factorial exploratorio (AFE). O sea permiten estimar cuánto se manifiesta una determinada dimensión latente en cada persona, según sus respuestas a las variables observadas.
