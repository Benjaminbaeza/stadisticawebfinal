🎯 Objetivo del Análisis

Este script realiza un análisis de conglomerados para identificar perfiles de confianza institucional en América Latina utilizando datos del Latinobarómetro. Las variables miden confianza en cuatro instituciones en escala Likert (1-4):

Variable Institución P34NI.BB Confianza en los empresarios P34NI.BE Confianza en los partidos políticos P34NI.BD Confianza en el Congreso Nacional P34NI.BC Confianza en el Poder Judicial

Enfoque metodológico:

  • Escalas Likert tratadas como numéricas (1-4)

  • Distancias euclidianas para medir similitud

  • Método de Ward para clustering jerárquico

  • K-means para validación y asignación de clusters

  • PCA para visualización en 2 dimensiones

📚 Fundamentos Teóricos

¿Qué es el método de Ward? El método de Ward (o Ward.D2) es un algoritmo de clustering jerárquico que minimiza la varianza intra-cluster. En cada paso, fusiona los dos clusters que producen el menor incremento en la suma total de cuadrados dentro de los grupos.

Ventajas:

  • Produce clusters compactos y esféricos

  • Muy utilizado en ciencias sociales

  • Robusto y con buena interpretación

Desventajas:

  • Sensible a outliers

  • Tiende a crear clusters de tamaño similar

¿Por qué combinar Ward, k-means y PCA?

  • Ward: Nos da la estructura jerárquica y ayuda a decidir k

  • K-means: Asigna casos a clusters de manera óptima dado k

  • PCA: Reduce dimensionalidad para visualizar los clusters en 2D

🔢 4. Asegurar Tipo Numérico

¿Qué hacemos? Convertimos las variables Likert a numéricas.

¿Por qué? Aunque son ordinales, para clustering las trataremos como numéricas (1-4). Esto es común cuando las categorías tienen un orden claro y equidistancia asumida.

# Identificar columnas que son variables Likert
likert_cols <- intersect(names(lb), names(nuevas_labels))
cat("Variables Likert identificadas:", paste(likert_cols, collapse = ", "), "\n")

# Convertir a numéricas (parse_number extrae el número aunque venga como texto)
lb <- lb %>%
  mutate(across(all_of(likert_cols), ~ parse_number(as.character(.x))))

# Verificar
summary(lb[, likert_cols])

Interpretación: Ahora las variables tienen valores entre 1 y 4 (o NA si hay perdidos).

🧹 5. Selección y Limpieza

¿Qué hacemos? Seleccionamos solo variables numéricas y eliminamos casos con NA.

¿Por qué? El clustering requiere datos completos (sin valores perdidos).

# Seleccionar solo columnas numéricas
num_cols <- names(lb)[sapply(lb, is.numeric)]
cat("Variables numéricas disponibles:", paste(num_cols, collapse = ", "), "\n")

# Eliminar filas con NA en esas variables
lb_limpio <- lb %>% 
  select(all_of(num_cols)) %>% 
  drop_na()

# Ver cuántos casos se perdieron
cat("Casos después de limpiar NA:", nrow(lb_limpio), "\n")
cat("Casos eliminados:", n_total - nrow(lb_limpio), 
    "(", round(100 * (n_total - nrow(lb_limpio))/n_total, 1), "%)\n")

Interpretación: Hemos perdido algunos casos con NA, pero ahora tenemos una matriz completa para el clustering.

📊 7. Determinar Número de Clústeres (Método del Codo)

¿Qué hacemos? Usamos k-means para evaluar diferentes números de clusters y graficamos la suma de cuadrados intra-cluster.

¿Por qué? El método del codo nos ayuda a elegir k: buscamos el punto donde la curva deja de caer bruscamente.

# Evaluar k de 1 a 10
k.max <- 10
wss <- sapply(1:k.max, function(k) {
  km <- kmeans(X, centers = k, nstart = 25, iter.max = 100)
  km$tot.withinss  # Suma de cuadrados intra-cluster
})

# Graficar
plot(1:k.max, wss, 
     type = "b", 
     pch = 19, 
     col = "blue",
     xlab = "Número de clusters (k)", 
     ylab = "Suma de cuadrados intra-cluster",
     main = "Método del Codo para elegir k")

# Añadir línea en el posible codo
abline(v = 2, col = "red", lty = 2, lwd = 2)  # Cambiar según el gráfico
abline(v = 3, col = "red", lty = 2, lwd = 2)

Interpretación: Buscamos el punto donde la disminución de WSS se estabiliza (forma de codo). En este caso, k=2 o k=3 son candidatos.

📏 8. Calcular Matriz de Distancias

¿Qué hacemos? Calculamos la matriz de distancias euclidianas entre todos los casos.

¿Por qué? Necesitamos esta matriz para el clustering jerárquico.

# Calcular distancias euclidianas
dist_euclidea <- dist(X, method = "euclidean")

# Ver estructura
str(dist_euclidea)

# Distancias entre primeros 5 casos
as.matrix(dist_euclidea)[1:5, 1:5]

🌲 9. Clustering Jerárquico con Método de Ward

¿Qué hacemos? Aplicamos clustering jerárquico con el método de Ward.D2.

¿Por qué? Ward.D2 recibe distancias simples y las eleva internamente al cuadrado y minimiza la varianza intra-cluster.

# Clustering jerárquico con Ward.D2
hc <- hclust(dist_euclidea, method = "ward.D2")

# Visualizar dendrograma
plot(hc, 
     hang = -1, 
     main = "Dendrograma - Método de Ward",
     xlab = "Casos", 
     ylab = "Altura (distancia)")

✂️ 10. Elegir Número de Clústeres (k)

¿Qué hacemos? Decidimos k basado en el método del codo y la interpretabilidad.

# Elegir k (ajustar según análisis)
K <- 2  # Cambiar a 3 si corresponde

# Cortar el dendrograma
clusters_hc <- cutree(hc, k = K)

# Ver distribución
cat("Distribución de clusters (k =", K, "):\n")
print(table(clusters_hc))

🔄 11. K-means para Asignación Óptima

¿Qué hacemos? Usamos k-means para refinar la asignación de clusters.

¿Por qué? K-means optimiza la asignación minimizando la distancia a los centroides, complementando el análisis jerárquico.

# K-means con el mismo k
set.seed(123)  # Para reproducibilidad
km <- kmeans(X, centers = K, nstart = 50, iter.max = 100)

# Asignaciones
clusters_km <- factor(km$cluster)

# Comparar con clustering jerárquico
tabla_comparacion <- table(Hierárquico = clusters_hc, Kmeans = clusters_km)
print(tabla_comparacion)

📈 13. Caracterización de los Clústeres

¿Qué hacemos? Calculamos los promedios de cada variable por cluster para entender los perfiles.

# Variables de interés (las originales)
vars_interes <- names(nuevas_labels)[names(nuevas_labels) %in% colnames(resultados_km)]

# Calcular medias por cluster
resumen_km <- resultados_km %>%
  group_by(Cluster) %>%
  summarise(
    across(all_of(vars_interes),
           ~ mean(as.numeric(.x), na.rm = TRUE),
           .names = "{.col}"),
    n = n(),
    .groups = "drop"
  )

# Renombrar con etiquetas legibles
for (i in seq_along(vars_interes)) {
  old_name <- vars_interes[i]
  new_name <- nuevas_labels[old_name]
  if (!is.na(new_name) && new_name != old_name) {
    colnames(resumen_km)[colnames(resumen_km) == old_name] <- new_name
  }
}

# Mostrar resultados
print(resumen_km)

# Tamaños de cluster
cat("\nTamaños de cluster:\n")
print(table(clusters_km))

🎨 14. Visualización con PCA

¿Qué hacemos? Reducimos dimensionalidad con PCA para visualizar los clusters en 2D.

¿Por qué? Es difícil visualizar clusters en 4 dimensiones. PCA nos da una “vista satelital”.

14.1 Realizar PCA

# PCA con escalamiento (recomendado para Likert)
pca <- prcomp(X, center = TRUE, scale. = TRUE)

# Ver resumen
summary(pca)

# Varianza explicada
varianza_explicada <- (pca$sdev^2) / sum(pca$sdev^2)
cat("Varianza explicada:\n")
for (i in 1:4) {
  cat("PC", i, ": ", round(100 * varianza_explicada[i], 1), "%\n", sep = "")
}

14.2 Preparar datos para graficar

# Extraer puntajes de las primeras dos componentes
scores <- as.data.frame(pca$x[, 1:2])
names(scores) <- c("PC1", "PC2")
scores$Cluster <- clusters_km

# Calcular centroides por cluster en el espacio PCA
centroides <- scores %>%
  group_by(Cluster) %>%
  summarise(PC1 = mean(PC1), PC2 = mean(PC2), .groups = "drop")

# Título con varianza explicada
tit <- sprintf("PCA: Confianza institucional (PC1: %.1f%%, PC2: %.1f%%) – coloreado por clúster",
               100 * varianza_explicada[1], 100 * varianza_explicada[2])

14.3 Graficar

# Gráfico PCA con clusters
ggplot(scores, aes(x = PC1, y = PC2, color = Cluster)) +
  # Puntos de casos
  geom_point(alpha = 0.7, size = 2) +
  # Elipses de confianza (95%)
  stat_ellipse(type = "t", linewidth = 0.8, alpha = 0.5) +
  # Centroides
  geom_point(data = centroides, 
             aes(x = PC1, y = PC2, color = Cluster),
             size = 6, shape = 18, show.legend = FALSE) +
  # Etiquetas de centroides
  geom_text(data = centroides,
            aes(x = PC1, y = PC2, label = paste("Cluster", Cluster)),
            vjust = -1, size = 4, fontface = "bold") +
  # Título y etiquetas
  labs(title = tit,
       x = paste0("PC1 (", round(100 * varianza_explicada[1], 1), "%)"),
       y = paste0("PC2 (", round(100 * varianza_explicada[2], 1), "%)"),
       color = "Cluster") +
  # Tema
  theme_minimal(base_size = 12) +
  theme(legend.position = "bottom",
        plot.title = element_text(hjust = 0.5, face = "bold"))

Interpretación del PCA:

PC1 (eje horizontal): [ej. Contraste entre confianza general vs desconfianza]

PC2 (eje vertical): [ej. Contraste entre confianza en instituciones políticas vs económicas]

Separación de clusters: [ej. Los clusters se separan claramente en PC1]

⚠️ Notas Metodológicas Importantes

  1. Tratamiento de escalas Likert Se trataron como numéricas asumiendo equidistancia entre categorías

Alternativa: usar distancia de Gower para variables mixtas

  1. Estandarización En el clustering usamos datos sin estandarizar (las escalas ya son comparables: 1-4)

En PCA sí estandarizamos (scale. = TRUE) para dar igual peso a todas

  1. Validación cruzada Comparamos Ward (jerárquico) con k-means (particional)

La alta concordancia entre métodos valida la solución

  1. Limitaciones Análisis sensible a outliers

La elección de k tiene un componente subjetivo

Se asume independencia de observaciones
