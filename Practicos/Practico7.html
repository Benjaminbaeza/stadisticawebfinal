Objetivo del Análisis

El ACP (o PCA por sus siglas en ingles) es una técnica estadistica, como se menciono en el practico anterior, con este podriamos reducir el número de variables de un conjunto de datos, conservado la mayor cantidad posible de información.

En este presente practico, se tiene como objetivo que los y las estudiantes realicen otro ejercicio de Análisis de Componentes Principales con el fin de que sigan comprendiendo y familiarizandose con el metodo; para aquello se realizara otro ACP, manteniendo el formato de dos formas distintas de elaborarlo por medio de las posibilidades que permite el software de Rstudio. Este pracito incluye como complemento visualizaciones referente a los componentes principales.

Ejercicio a desarrollar

Siguiendo los siguientes pasos en la base de datos del ELSOC, se realizara un Analisis de Componentes Principales; a partir de las variables correspondientes al módulo de Ciudadania y asociados a los conceptos de rabia y miedo siendo 8 variables en total. Se realizara el ACP, con el fin de reducir el conjunto de datos, manteniendo la mayor cantidad de información posible y se realizaran distintos graficos para aportar con su visualización y comprensión.

3.4 Limipieza de NA de la sub-base de datos definitica

# Eliminamos los NA, de la sub-base creando otra sub-base de datos.

# El eliminar los NA, se puede realizar de distintas formas;
# en este pracitco usamos tidyr::drop_na() pero tambien se puede
# usar el comando na.omit, es cuestión de estilos
# en los practicos se realizan estas acciones de distintas maneras
# a pesar de que puede suponer que los practicos no sean consistentes
# entre si, para que conozcan la mayor cantidad de formas distintas
# y posibles de proceder.

proc_data_pca <- proc_data %>%
  tidyr::drop_na()

# Otra cuestión, creamos una nueva sub-base de datos, pese a poder
# reescribir la misma base con los NA eliminados.
# Estos se hace con el fin de comparar ambas bases y poder
# determinar cuantos casos se perdieron. Recordemos que lo ideal
# en caso de eliminar casos es que sea menos del 15 % siendo
# muy flexibles (lo ideal menos del 10%)

# Comprobamos las dimensiones de la sub-base final

dim(proc_data_pca)

# Comprobamod que todas las variables tengan variabilidad
# o sea calculamos la desviación estandar

sapply(proc_data_pca, sd)

# EXTRA: Verificamos que las variables sean numéricas y no constantes

stopifnot(
  ncol(proc_data_pca) == 8,
  all(vapply(proc_data_pca, is.numeric, logical(1))),
  all(vapply(proc_data_pca, sd, numeric(1)) > 0))

# Recordemos que esto es en el caso de que estemos trabajando con
# variables que no sean numericas  o en caso que, como dice el 
# extra, hayamos tomado o pasado por alto alguna variable constante.

Paso 4: Matriz de correlaciones

4.1 Elaboración y visualización de la matriz de correlaciones

matriz_cor <- cor(proc_data_pca) # cor, es el apócope/acortamiento/abreviación
                                 # de la palabra correlation; correlación en
                                 # ingles

matriz_cor # Se le indicamos R que corra el objeto creado, nos permitira
           # observar en la consola, la correlación entre las variables

round(matriz_cor, 2) # otra forma de visualizar la matriz de correlación 
                     # en la consola; pero indicando que redonde los
                     # resultados y solo tome los dos primeros
                     # decimales

# Comenzamos con la visualización de la matriz de correlaciones

datos_cor <- as.data.frame(matriz_cor) %>%
  tibble::rownames_to_column("Variable1") %>%
  tidyr::pivot_longer(
    cols = -Variable1,
    names_to = "Variable2",
    values_to = "Correlacion")

# Creamos el objeto datos_cor, el cual volvemos un data.frame para su analisis
# tambien renombramos filas, columnas y valores, para que la matriz una vez
# graficada, mantenga dichas etiquetas.

grafico_cor <- ggplot(
  datos_cor,
  aes(
    x = Variable1,
    y = Variable2,
    fill = Correlacion
  )) +
  geom_tile(color = "white") +
  geom_text(
    aes(label = sprintf("%.2f", Correlacion)),
    size = 3) +
  scale_fill_gradient2(
    low = "blue",
    mid = "white",
    high = "red",
    midpoint = 0,
    limits = c(-1, 1)) +
  coord_equal() +
  labs(
    title = "Matriz de correlaciones",
    subtitle = "Emociones frente a situaciones de las protestas",
    x = NULL,
    y = NULL,
    fill = "Correlación") +
  theme_minimal() +
  theme(
    axis.text.x = element_text(
      angle = 45,
      hjust = 1
    ),panel.grid = element_blank())

# El codigo es un poco largo en extensión; pero como sintesis,
# durante el desarrollo de este, asignamos colores a los valores que
# podian adoptar las correlaciones; azul en caso de ser negativa,
# roja en caso de ser positiva.
# Tambien se asigno un color para el fondo, se asigno las etiquetas
# y su distribución, se ajuto el angulo de las variables entre otros
# elementos entre los que estaria la asignación de un titulo y
# subtitulo.

print(grafico_cor) # Visualizamos la matriz de correlaciones
