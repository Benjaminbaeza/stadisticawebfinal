Objetivo del ejercicio

En el presente tiene como objetivo que los estudiantes realicen un Analisis de Conglomerados No Jerárquico con la base de datos de ELSOC; se espera que con la realización de este, los estudiantes logren comprender su forma de proceder y interpretar su resultados a partir de los datos obtenidos. Se agrega como elemento extra, formas de determinar el numero de clusters con el que proceder, por via del uso del analisis de siluetas y el método del codo Se espera que con el desarrollo del mismo, se entienda la diferencia entre un Analisis de Conglomerados Jerarquico (el cual se emplea de forma explotaria para determinar un numero de clusters determinado para una serie de variables, practico anterior) con el Analisis de Conglomerados No Jerarquico, el cual opera con un numero de clusters predeterminado.

Ejercicio a desarrollar

Siguiendo los siguientes pasos en la base de datos del ELSOC, se realizara un Analisis de Conglomerados No Jerarquico, en donde con las variables correspondientes al módulo de Conflicto Social se elaboraran o categorizaran tres clusters o perfiles en lo referente a la Aversión al conflito.

Dichas variables del módulo Conlficto social seran:

f02_01: Si discrepo con otros prefiero no discutir f02_02: Dificultad para expresar mi opinión si difiere del resto
f02_03: Siento que el conflicto es algo negativo f02_04: Siento que en los conflictos alguien saldrá perjudicado

EXTRA 1 - Determinación del numero de clusters (Análisis de Silueta)

Como hablamos en clase y vimos en el practico anterior, el metodo jerarquico nos permite observar cuantos clusters se forman a partir de los datos pero existen otras formas de comprobar el numero de clusters que se forman y cual de estos es el más factible o pertinente a realizae; funciona como otra forma de justificar porque seleccionamos un numero de clusters concreto

# El metodo de la silueta es uno de los metodos más utilizados

sil <- silhouette(modelo_kmean$cluster,
                  dist(datos_CNJ_std))

# creamos un objeto cuya abreviación es sil de silueta

plot(sil)

# si lo graficamos obtenemos la anchura promedio de la silueta 
# que nos permite evaluar qué tan bien separados están los grupos.

mean(sil[, 3])

# tambien podemos calcular su valor, 
# un valor más alto indica, en términos generales, una mejor separación 
# de los casos entre conglomerados.

# Ahora probaremos con otro numero de coglomerados

set.seed(123) # aseguramos que los datos sean replicables

# Dos conglomerados
k2 <- kmeans(datos_CNJ_std, centers = 2, nstart = 25)

# Tres conglomerados
k3 <- kmeans(datos_CNJ_std, centers = 3, nstart = 25)

# Cuantro conglomerados
k4 <- kmeans(datos_CNJ_std, centers = 4, nstart = 25)

# Cinco conglomerados
k5 <- kmeans(datos_CNJ_std, centers = 5, nstart = 25)

# Con este codigo podemos comparar la suma de sus cuadrados interna

k2$tot.withinss
k3$tot.withinss
k4$tot.withinss
k5$tot.withinss

sil2 <- silhouette(k2$cluster, dist(datos_CNJ_std))
sil3 <- silhouette(k3$cluster, dist(datos_CNJ_std))
sil4 <- silhouette(k4$cluster, dist(datos_CNJ_std))
sil5 <- silhouette(k5$cluster, dist(datos_CNJ_std))

# Podemos observar el valor de cada uno de estos de forma
# separada

mean(sil2[, 3])
mean(sil3[, 3])
mean(sil4[, 3])
mean(sil5[, 3])

EXTRA 2 - Determinación del numero de clusters (Método del codo)

Con el metodo de la silueta podemos observar que la suma de cuadrados disminuye a medida que aumentamos el número de clusters, por lo que no basta con escoger simplemente el valor más bajo. Podemos utilizar el método del codo de esta apartado para observar dónde deja de existir una mejora importante.

# Realizamos el método del codo

wss <- numeric(10)

set.seed(123)

for (k in 1:10) {
  modelos_k <- kmeans(datos_CNJ_std,
                   centers = i,
                   nstart = 25)
  
  wss[i] <- modelos_k$tot.withinss
}

# Y graficado podemos buscar el punto donde agregar más conglomerados 
# empieza a producir una mejora relativamente pequeña.

plot(1:10,
     wss,
     type = "b",
     xlab = "Número de conglomerados",
     ylab = "Suma de cuadrados dentro de los grupos",
     main = "Método del codo")
