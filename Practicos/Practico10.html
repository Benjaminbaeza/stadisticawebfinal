Objetivo del Análisis

En este practico se propone realizar un Analsis Factorial Exploratorio (AFE), con el fin de que los estudiante sigan famirializandose con el mismo; se pone un especial enfasis en la obtención del valor denominado como Alfa de Cronbach indicador estadístico que permite evaluar la consistencia interna de un conjunto de preguntas o ítems; a partir de este y los datos obtenidos del propio indice, se planteara tambien la realización de un indicadores compuestos a partir de las variables seleccionadas para medir fenomenos más complejos; se agregan como elementos extras la realización de una Matriz de correlaciones policoricas y la obtención del Alfa Ordinal.

Ejercicio a desarrollar

A partir de 8 variables correspondientes al modulo al modulo de “Territorio” de la encuesta ELSOC y correspondientes a los conceptos de Cohesión barrial y Sociabilidad barrial; se esperar realizar en este practico los pasos previos para el Analisis Factorial Exploratorio (AFE) en donde se contempla la realización de una matriz de correlaciones de Pearson y una matriz de correlaciones policorica, ademas de la obtención de los Alfa de Cronbach y Alfa Ordinal de las mismas; posteriormente se realizaran indicadores compuestos a partir de las mismas, para finaminalmente elaborar a partir de estas un indicador general con el fin de evaluar el fenomeno.

EXTRA 2: Matriz de correlaciones policoricas

Durante este practico y en el paso, realizamos un tipo de correlación denominado como correlación de Pearson, pero este presenta ciertas limitaciones como en este caso en donde estamos trabajando con variables ordinales; por eso como extra en este paso realizaremos correlaciones policoricas. Estas son un tipo de correlación estadística que permite medir la relación entre dos variables ordinales, como las preguntas de una escala Likert por ejemplo.

Para quienes quieran consultar el listo de variables del ELSOC (disponible en Ucampus) podran observar que las variables seleccionadas tienen categorias de respuestas que van desde: “Muy en desacuerdo” (1) a “Muy de acuerdo” (5).

Aunque podemos representar estas respuestas con números del 1 al 5, esos números son categorías ordenadas. No necesariamente podemos asumir que la distancia psicológica entre 1 y 2 es idéntica a la distancia entre 4 y 5.

De todas formas, sigue siendo valido trabajar con la correlación de Pearson como en los practicos anteriores para trabajos futuros siempre que lo expliciten en los apartados metodologicos, ya que nuevamente esto es solo un contenido extra en este practico.

# Debido a que las variables son ordinales (1 a 5),
# utilizaremos correlaciones policoricas para el AFE

Paso 9: Alfa de Cronbach

Pese a que esta indicado en los objetivos del analsis vale la pena recordar que es el Alfa de Cronbach este es un coeficiente estadístico que permite medir la consistencia interna de un conjunto de preguntas o ítems. Por lo que con su uso podemos evaluar si las preguntas que utilizamos para medir una misma dimensión están relacionadas entre sí y funcionan de manera coherente.

Valores inferiores a 0.60 nos indican una consistencia baja; valores entre 0.61 y 0.69, puede ser aceptables pero los resultados pueden estar sujetos a dudas; idealmente buscamos valores por encima de 0.70 o más.

# que agrupen las variables dentro de sus parentesis corresponderan
# al apartado de indice_cohesión; lo mismo sucede en la "segunda"
# parte del codigo donde se repite los mismo para el 
# indice_sociabilidad

# Con rowSums sumamos las respuestas válidas por fila, 
# es decir, por participante 

# !is.na es para identificar las variables que si esten disponibles

# Con pick, seleccionamos las variables; el dos puntos (:)
# indica que se seleccionen todas las variables entre medio de las
# dos variables escritas

# >= 3, establece que el participante debe tener al menos tres 
# de las cuatro respuestas disponibles; este paso se mantiene para
# enseñarles la estructura y la logica, mas en caso de estar
# trabajando con una base de datos donde eliminaron los casos con
# los valores peridos no resulta necesario

# Con rowMeans, calculamos el promedio horizontalmente, 
# es decir, entre las columnas de cada fila.

# na.rm = TRUE o na.rm = T; excluye los valores faltantes del cálculo.
# nuevamente aquello no resulta necesario en una base de datos que
# tenga los NA, eliminados.

# NA_real_ indica específicamente que el valor faltante corresponde 
# a una variable numérica.

# Por lo que deforma general el if_else esta diciendo; 
# Si tiene tres o cuatro respuestas válidas, calcula el promedio.
# Si tiene menos de tres respuestas válidas, asigna NA. 
# las variables de t02_01 a t02_04 agrupalas en el indice_cohesion;
# las variables de t03_01 a t03_04 agrupalas en el indice:sociabilidad

# Como estamos ocupando la sub-base original con los NA sin eliminar
# los puntos refentes a los NA, para este caso resultan utiles y 
# tienen sentidos.

base_indices <- base_afe %>%
  mutate(

    # INDICE DE COHESION BARRIAL
  indice_cohesion = if_else(
      rowSums(!is.na(pick(t02_01:t02_04))) >= 3,
      rowMeans(pick(t02_01:t02_04), na.rm = TRUE),
      NA_real_
    ),
    
    # INDICE DE SOCIABILIDAD BARRIAL
    indice_sociabilidad = if_else(
      rowSums(!is.na(pick(t03_01:t03_04))) >= 3,
      rowMeans(pick(t03_01:t03_04), na.rm = TRUE),
      NA_real_
    )
  )

10.4. Normalización de los indices

# Una vez que realizamos el paso anterior de creación de los
# indicadores en la nueva sub-base se nos debieron de crear
# dos variables nueva (por lo que la sub-base debe tener dos
# más que las otras).

# En este paso vamos a normalizar los indices para que asi 
# puedan tener una misma escala de interpretación y 
# posteriormente podamos combinarlos para construir el 
# indicador que denominaremos como:
# Indicador de Cohesión y Sociabilidad Barrial (ICSB).

# El siguiente codigo nuevamente es uno solo y debe ser ejecutado
# como uno solo, este fue separado para enteder su logica y partes
# y explicar el paso a paso.

# Recordemos que mutate puede transformar y crear nuevas variables
# por lo que crearemos unas nuevas variables que denominariamos 
# como cohesion_100 y sociabilidad_100.

# En "((indice_cohesion - 1) / 4) * 100" transformamos las 
# puntuaciones de las cohesión, originalmente expresadas con 
# valores de entre 1 y 5, a una escala de 0 a 100.

# cohesion_100 y sociabilidad_100, mediaran la puntuación de los
# indices de cohesion y sociabillidad en dicha escala

base_indices <- base_indices %>%
  mutate(
    
    cohesion_100 =
      ((indice_cohesion - 1) / 4) * 100,
    
    sociabilidad_100 =
      ((indice_sociabilidad - 1) / 4) * 100
  )

# Si el resultado sale bien, ahora la sub-base base_indices
# debe tener dos variables más nuevas, las cuales serian 
# como se diho anteriormente cohesion_100 y sociabilidad_100

Paso 11: Construcción del Indicador General ICBS

11.1. Construcción

# Por ultimo construimos el Indicador General ICBS
# para eso crearemos una nueva variable la cual
# agregaremos a la sub-base de datos, teniendo una
# ultima variable extra, la cual seria ICBS

# recordemos que con mutate como se a dicho multiples
# veces, permite manipular o transformar variables

# Empleando if_else el cual recordemos que nos permite
# trabajar o manipular los datos, para que reciban el 
# mismo trato, permitiendonos mantener las clases o 
# los atributos originales de los datos.

# Indicamos con el !is.na que se compruebe que el 
# valor esté disponible.

# E (&) indica que ambas condiciones deben cumplirse
# en caso que no sea asi,  NA_real_ indicaria 
# específicamente que el valor faltante corresponde 
# a una variable numérica.

# Por ultimo con (cohesion_100 + sociabilidad_100) / 2,
# estamos calculando el promedio de forma directa
# sumamos ambos valores y los dividimos por el
# numero de los mismos

# Este comando al igual que los anteriores debe ser
# ejecutado como uno solo, fue divido en partes,
# para facilitar su explicación

base_indices <- base_indices %>%
  mutate(
    ICSB = if_else(
      !is.na(cohesion_100) &
        !is.na(sociabilidad_100),
      
      (cohesion_100 + sociabilidad_100) / 2,
      
      NA_real_
    )
  )
